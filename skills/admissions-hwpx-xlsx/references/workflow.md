# 판독과 검증 기준

## HWPX 판독

HWPX는 압축 컨테이너다. 우선 문서 XML·본문 텍스트를 확인하고, 지원서 화면이 `BinData` 이미지로만 들어 있는 경우에는 각 페이지를 시각적으로 읽는다. 지원 대학 수, 대학명, 학과명, 전형명이 모두 보이는지 행별로 대조한다.

텍스트 추출 결과와 화면이 다를 때에는 화면상 선명하게 읽히는 값을 우선한다. 식별이 불가능한 행은 “가려짐/판독 불가”로 따로 보고하며, 비슷한 대학·학과를 추정해 채우지 않는다.

## 모집요강 조사

지원서의 연도 또는 사용자가 지정한 모집연도를 기준으로 한다. 각 대학의 공식 입학처 페이지에서 해당 연도의 `수시 모집요강` 또는 전형별 공지를 찾는다. 다음을 구분한다.

- 면접: 전형별 면접일 또는 면접고사일
- 실기: 실기·특기고사일이며 면접 칸에는 넣지 않음
- 제출 서류: 온라인 제공 동의 여부에 따른 제출 여부와 전형별 필수 서류
- 마감: 서류제출 마감과 우편마감의 날짜·시간·소인/도착 조건

전형 이름이 모집요강과 약간 다르면 대학·학과·전형군을 함께 대조한다. 동일성을 확신할 수 없으면 날짜를 확정하지 않는다.

## Excel 작성

`assets/fixed-application-tracker.xlsx`를 복사해 출력 파일을 만든다. 제목, 헤더, 열 순서, 병합 구조와 기본 6개 행의 구조는 고정한다. 열은 `지역 / 대학 / 학과 / 제출 서류 / 조건/주의 사항 / 마감-서류제출 / 마감-우편마감 / 전형` 순서다. 마감은 시간·소인·도착 조건을 보존해야 하므로 공식 표기대로 입력한다. 면접은 별도 열을 만들지 않고 `조건/주의 사항`에 `면접: ...`으로 기록하며, 실기는 `실기: ...`으로 구분한다.

검증 시에는 다음을 다시 확인한다.

1. 지원자명·대학·학과·전형이 HWPX에서 추출한 값과 일치하는지
2. 제출 서류와 두 마감 열이 전형별 공식 출처와 일치하는지
3. `조건/주의 사항`의 면접·실기·확인 필요 표시가 공식 일정과 충돌하지 않는지
4. 새 행도 기존 테두리·줄바꿈·병합 구조와 행 높이를 유지하는지
